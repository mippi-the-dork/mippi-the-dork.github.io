## Design Intent

The Tools section should not imply that useful Unreal development knowledge comes only from Mippi's own plugins.

The resource cards acknowledge the broader community and official learning ecosystem.

The current recommendation is intentionally small: two high-value destinations rather than a directory of links.

## Unreal Source

Unreal Source is framed as a developer community where people share:

- answers,
- workflows,
- discoveries,
- hard-earned lessons.

The card provides both the website and Discord community as distinct actions.

## Epic Learning Center

Epic's learning ecosystem is framed as the official source for:

- courses,
- tutorials,
- demos,
- recorded sessions,
- live streams,
- talks,
- knowledge bases,
- learning paths,
- example projects.

The card provides a curated Epic learning link plus `learn.unrealengine.com`.

## Design Rules

- Keep recommendations genuinely useful.
- Distinguish community resources from official Epic resources.
- External links should be explicit.
- Resource cards should not become required progression.
- Avoid turning this area into advertising.
- Claims such as community size should be reviewed periodically because they can become stale.
- If an external URL changes, fix the link rather than leaving a dead recommendation.

## Relationship to Heart Reward

Unreal Source is also used by the five-Heart reward elsewhere in the game layer.

The resource card remains the professional, always-available route. The Heart reward is an optional playful reinforcement, not the only path to Unreal Source.

## Success Criteria

An Unreal developer should be able to leave the section with at least one useful community or official learning destination even if they ignore the portfolio game layer.
