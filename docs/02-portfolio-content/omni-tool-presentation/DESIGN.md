## Design Intent

Omni is presented as an active public Unreal Engine R&D tool focused on area-based navigation links.

Its portfolio purpose line is:

`Area navigation links`

The card should communicate enough to make the tool interesting without pretending the design is finalized.

## Product Identity

Omni explores volume-to-volume and related continuous navigation-link authoring workflows.

The site card intentionally stays broad because the plugin is still being developed and tested.

## Visual Identity

The card uses the official Omni icon supplied by Mippi.

The icon's geometry is the canonical identity. Site styling may adapt color treatment to the Unreal Tools visual system, but should not replace the symbol with a generated approximation.

## Status

Current status:

`WIP · PUBLIC`

The repository is public, but the tool is not presented as a released FAB product.

## Design Rules

- Keep current purpose text broad enough to survive implementation changes.
- Show public availability through GitHub.
- Do not imply production readiness through Released styling.
- Preserve the official icon.
- When the tool reaches public release, update presentation as one coordinated change.

## Success Criteria

The card should make Omni feel like a legitimate active tool project while setting correct expectations about maturity.
