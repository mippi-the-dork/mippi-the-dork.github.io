## Design Intent

Portal is presented as a public work-in-progress Unreal tool rather than a finished release.

Its card should communicate the concept quickly:

`Blueprint named reroutes`

The purpose is to show active tool development while remaining honest about release status.

## Product Identity

Portal is the planned Unreal Engine plugin that brings the concept of named reroute nodes to Blueprints.

The portfolio card does not need to explain the complete technical design. Its job is to give the idea a recognizable identity and provide a path to the public repository.

## Visual Identity

The card uses the official Portal icon supplied by Mippi.

The website should preserve the shape and transparency of the icon while applying the same overall presentation language as the rest of the tool family.

The icon should not be replaced with an invented symbol merely for consistency.

## Status

Current visible state:

`WIP · PUBLIC`

This means:

- the project is actively in development,
- the repository is public,
- it is not presented as a released FAB product.

## Design Rules

- Keep the purpose line short.
- Make WIP state unmistakable.
- Provide GitHub as the current destination.
- Do not display a FAB price or release call-to-action until a release exists.
- Keep the official icon recognizable through theme treatment.
- When Portal releases, update both visible status and machine-readable status tokens.

## Success Criteria

The visitor should understand that Portal is real, public, actively developed, and not yet positioned as a finished release.
