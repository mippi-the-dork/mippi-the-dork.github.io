## Design Intent

Project Heavy Water is the featured game project because it communicates a design problem immediately: what happens when second-person perspective is treated as a gameplay constraint rather than a visual gimmick?

The feature is meant to demonstrate design reasoning, not only announce that a project exists.

## Core Message

The project is described as an experimental horror title built around second-person perspective.

The portfolio emphasizes that perspective affects:

- navigation,
- tension,
- vulnerability,
- decision-making.

This framing makes the camera model part of gameplay design.

## Information Structure

The feature presents:

- development status,
- game-design and direction role,
- project title,
- concise project description,
- Perspective fact,
- Genre fact,
- Focus fact,
- interactive Perspective Visualizer.

The facts are deliberately short. The visualizer is where the visitor can explore the underlying idea.

## Perspective Visualizer Role

The visualizer compares first-person, second-person, and third-person camera ownership.

It is not decorative media. It is an interactive explanation of the design premise.

The feature should still make sense if the visualizer is not used, but using it should deepen understanding.

The visualizer itself has separate canonical documentation under the Perspective Visualizer category.

## Design Rules

- Heavy Water should read as a design case study teaser, not a store page.
- Do not imply features or release information that are not established.
- Keep the design focus on perspective and player experience.
- The visualizer should clarify who the player controls and whose perspective supplies the camera.
- The project remains the strongest visual element in Games.
- Avoid filling the feature with unrelated production details that dilute the perspective thesis.

## Discovery Relationship

Using the Perspective Visualizer is connected to the Rare achievement `Second Perspective`.

That achievement rewards curiosity but does not gate project information.

## Success Criteria

A visitor who spends less than a minute with the feature should understand:

- Heavy Water is in development.
- It is a horror project.
- Mippi is responsible for design and direction.
- second-person perspective is the defining design experiment.
- there is an interactive tool available to make the concept legible.
