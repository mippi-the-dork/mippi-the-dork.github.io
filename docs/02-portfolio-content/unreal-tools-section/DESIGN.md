## Design Intent

The Unreal Tools section demonstrates a specific design and development habit: when a workflow repeatedly creates friction, build the missing tool.

The section should communicate both the individual plugins and the larger pattern behind them.

The headline summarizes the philosophy:

`Small tools. Specific problems.`

## Section Layers

The section contains several distinct content layers.

### Filters

Visitors can filter the primary public tool catalog by release and visibility state.

### Store Positioning

A small note explains the distribution model:

- FAB versions at a low price for convenience or support.
- GitHub versions available free where applicable.

### Public Tool Grid

The main grid contains released tools plus public WIP tools.

### Roadmap

A separate roadmap lists private WIP concepts that are not yet ready for public repository links.

### Feature Projects

Azure Altar and Unmark receive larger editorial treatment because they represent broader bodies of work.

### Developer Resources

Unreal Source and Epic Learning Center are recommended as useful destinations for Unreal developers.

### External Portfolio Links

GitHub and FAB buttons provide direct access to the broader public tool presence.

## Distribution Philosophy

The section should make the free GitHub path visible.

FAB is positioned as a convenience/support path, not a paywall around the work.

## Design Rules

- A tool card should explain its purpose in a few words.
- Status must be explicit.
- WIP should look intentionally unfinished, not broken.
- Private roadmap concepts should not imply public availability.
- Tool icons should feel like one family.
- Public links should never be fabricated for tools that are not public.
- The section should remain useful even if external stores are unavailable.
- Feature projects can be larger than standard tool cards when they need more explanation.

## Progression Relationship

The Tools section hosts several discovery interactions:

- WIP filter awards `Under Construction`.
- Unmark feature can award `Unmarked`.
- Azure Altar has an interactive gallery.

These are optional additions to a fully usable professional tools catalog.
