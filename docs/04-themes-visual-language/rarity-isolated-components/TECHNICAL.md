# Rarity-Isolated Components - Technical Documentation

**Hierarchy:** Documentation Home > Rarity Themes and Visual Language > Rarity-Isolated Components > Technical

**Implementation baseline:** Mippi Portfolio v2.78

**Feature summary:** Keeps rarity-owned elements such as achievement rows and Shop cards visually tied to their own rarity regardless of the active global theme.

## Achievement Markup

Ledger rows are generated by:

```js
ledgerEntryMarkup({
  num,
  data,
  found,
  rarity
})
```

Generated row class:

```text
ledger-entry rarity-rare
ledger-entry rarity-epic
ledger-entry rarity-legendary
```

Each row also contains:

```html
<span class="ledger-rarity">
  RARE / EPIC / LEGENDARY
</span>
```

## Achievement Rarity Mapping

Original achievements:

```js
rarity:'rare'
```

Postgame Epic achievements:

```js
rarity:'epic'
```

Legendary capstone:

```js
rarity:'legendary'
```

## CSS Isolation

Rare rows:

```css
.achievement-ledger
.ledger-entry.rarity-rare
```

Epic rows:

```css
.achievement-ledger
.ledger-entry.rarity-epic
```

Legendary rows:

```css
.achievement-ledger
.ledger-entry.rarity-legendary
```

The selectors do not depend on page body theme.

Important use of `!important` prevents higher-level theme styling from accidentally recoloring the rows.

## Shop Rarity Variables

Shop rarity sections define local custom properties.

Rare:

```css
--shop-rarity-primary:#2f93ff;
--shop-rarity-secondary:#67e8ff;
--shop-rarity-hot:#8fd6ff;
```

Epic:

```css
--shop-rarity-primary:#b13cff;
--shop-rarity-secondary:#67e8ff;
--shop-rarity-hot:#ff4fc8;
```

Legendary:

```css
--shop-rarity-primary:#ff9d25;
--shop-rarity-secondary:#43e0dc;
--shop-rarity-hot:#ffc83d;
```

Child Shop cards use these variables for:

- borders,
- backgrounds,
- grade text,
- price/support text,
- buttons,
- hover,
- focus,
- owned,
- equipped.

## Locked Items

Locked Shop cards can use lock presentation because their rarity is not yet fully interactive.

When unlocked, rarity variables become authoritative.

## Achievement Toast Rarity

The achievement toast removes previous rarity classes:

```js
rarity-rare
rarity-epic
rarity-legendary
```

then applies the newly unlocked achievement rarity.

This avoids a prior toast's rarity leaking into the next one.

## QA

Open the Ledger and Shop in:

- Rare page theme,
- Epic page theme,
- Legendary page theme.

For each active theme verify:

- Rare rows stay blue,
- Epic rows stay purple/pink,
- Legendary row stays gold/teal,
- Rare Shop cards stay blue,
- Epic Shop cards stay purple/pink/cyan,
- Legendary Shop cards stay gold/teal.

Also verify text rarity labels remain visible.
