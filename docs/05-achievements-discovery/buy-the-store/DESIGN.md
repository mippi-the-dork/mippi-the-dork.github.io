# Buy the Store - Design Documentation

**Hierarchy:** Documentation Home > Achievements and Discovery > Buy the Store > Design

**Implementation baseline:** Mippi Portfolio v2.78

**Feature summary:** Rewards purchasing every item in the Shop, including the Design Mode capstone.

> This page is the canonical design documentation for **Buy the Store** within the Achievements and Discovery category.

- [Achievements and Discovery Index](../README.md)

## Design Intent

Buy the Store is the economy mastery achievement.

It asks the player to fully engage with Rupees, item unlock requirements, and the Shop capstone.

## Condition

Every purchasable Shop item is owned.

This includes the final Design Mode unlock item.

## Design Rules

- Locked items do not count as purchased.
- The achievement cannot be completed by merely having enough Rupees.
- Equipped state is irrelevant.
- Previously purchased items remain counted after reload.
