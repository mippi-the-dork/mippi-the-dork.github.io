## Design Intent

Curious Mind is an onboarding achievement.

The Mippi logo looks like identity branding.

Clicking it reveals that the page rewards curiosity.

That makes it an ideal early Signal because the action is harmless and thematically appropriate.

## Teaching Goal

The achievement teaches:

> some normal-looking portfolio surfaces have secondary behavior.

This prepares the player to investigate other features without turning the whole page into obvious game buttons.

## Finale Reuse

Later, the same logo becomes the trigger for the normal Finale when Finale readiness is active.

This is deliberate reuse of learned interaction language.

## Design Rules

- The logo still functions as professional branding.
- The secret should not interfere with the brand's normal home-link behavior outside the logo mark.
- Finale-ready behavior takes priority later.
- The achievement should only unlock once.

## Success Criteria

A player can discover the hidden layer through one intuitive click without risking navigation loss or state damage.
