## Design Intent

The postgame Epic set converts the whole website into a visible mastery checklist.

These are not obscure secrets.

They ask the player to prove that they have meaningfully engaged with the major systems.

## Nine Epic Goals

The current set is:

1. Signal Saturation
2. Maximum Cool
3. Gold Standard
4. Reality Validated
5. Full Hearts
6. Buy the Store
7. Another Castle
8. Grand Tour
9. Air Superiority

Together they cover:

- discovery,
- Doug,
- rarity progression,
- Wish,
- collectibles,
- economy,
- Castle loop,
- professional page engagement,
- arcade mastery.

## Design Philosophy

No single subsystem dominates the list.

True completion requires broad understanding of the whole portfolio game.

## Historical Completion

Some Epic achievements should recognize things the player already did before the postgame tier was revealed.

For example, if Coolness was already maxed or Super Boss was already defeated, the postgame system should be able to acknowledge that history.

This prevents the reveal from demanding artificial repetition.

## Design Rules

- Epic conditions should be concrete.
- Previously completed qualifying actions should count.
- Epic goals should represent breadth.
- None should require external websites.
- The set should remain possible after the normal Finale.
- Legendary completion depends on all nine.

## Success Criteria

The Epic set feels like a fair summary of the whole experience rather than nine arbitrary chores added after the ending.
