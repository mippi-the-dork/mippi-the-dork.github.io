## Design Intent

The Rare Signal Set is the first hidden game.

Its purpose is to teach the visitor that normal portfolio surfaces can have secondary behavior.

The set contains exactly 10 original Signals.

## Signal Composition

The 10 Signals deliberately span different kinds of interaction:

- identity click,
- interactive demo,
- 3D navigation,
- filter use,
- ambient observation,
- deep career reading,
- repeated character interaction,
- tool-feature discovery,
- NDA-safe secret interaction,
- keyboard easter egg.

This creates breadth.

A player cannot complete the set by repeating one mechanic.

## Difficulty Curve

The set should begin with interactions likely to be found naturally and include a few less obvious discoveries.

It is not intended to require pixel hunting.

Hints and Cheat exist for recovery.

## Epic Gate

Completing all 10 Rare Signals unlocks Epic.

This makes the set a coherent first chapter rather than an arbitrary list.

## Design Rules

- Every Rare Signal must attach to an existing meaningful feature.
- Signals should span multiple sections.
- No Signal should require external websites.
- No Signal should require irreversible action.
- No Signal should gate professional content.
- All 10 must remain testable after future layout changes.

## Success Criteria

By the time a player reaches 10/10, they should understand that the website contains a systemic game layer and be ready for Epic progression.
