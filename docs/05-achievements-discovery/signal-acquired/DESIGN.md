# Signal Acquired - Design Documentation

**Hierarchy:** Documentation Home > Achievements and Discovery > Signal Acquired > Design

**Implementation baseline:** Mippi Portfolio v2.78

**Feature summary:** Rewards using a 3D Hero signal as navigation instead of treating the scene as decoration.

## Design Intent

Signal Acquired teaches that the Hero 3D scene is functional navigation.

The scene visibly says:

- drag,
- hover,
- click to jump.

This achievement confirms that using a 3D Signal is part of the portfolio's intended interaction language.

## Qualifying Interaction

Any successful Hero Signal navigation qualifies.

Current targets include:

- Games,
- Career,
- Consulting,
- Unreal Tools.

## Design Rules

- The navigation must remain useful after the achievement is earned.
- Header navigation remains a full alternative.
- A 3D failure must not block professional navigation.
- The achievement should occur on successful interaction, not mere hover.

## Success Criteria

The player understands that the 3D scene contains real navigation and not only animated decoration.
