# Under Construction - Design Documentation

**Hierarchy:** Documentation Home > Achievements and Discovery > Under Construction > Design

**Implementation baseline:** Mippi Portfolio v2.78

**Feature summary:** Rewards intentionally selecting the work-in-progress filter in the Unreal Tools section.

> This page is the canonical design documentation for **Under Construction** within the Achievements and Discovery category.

## Design Intent

Under Construction rewards a normal useful portfolio action.

The visitor chooses to inspect tools that are still being built.

That action reflects curiosity about process, not only finished output.

## Qualifying Interaction

Selecting:

```text
WIP
```

in the Unreal Tools filter bar qualifies.

## Design Rules

- WIP filter remains useful without the achievement.
- The achievement must not change filter output.
- The card state should remain honest.
- Public WIP tools should never be presented as released merely to make the achievement more dramatic.

## Success Criteria

The player receives a Signal for exploring unfinished work while the tool filter still behaves like a conventional filter.
