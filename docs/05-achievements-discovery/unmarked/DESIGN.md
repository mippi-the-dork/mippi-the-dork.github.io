## Design Intent

Unmarked ties discovery to one of the user's Unreal Engine tool projects.

The project identity is already a meaningful interactive surface.

The hidden achievement gives the player one more reason to inspect the visual presentation.

## Qualifying Interaction

Clicking the Unmark project identity button qualifies.

## Design Rules

- The Unmark feature remains useful without the achievement.
- The logo remains recognizable as a project identity.
- The button should remain keyboard accessible.
- The achievement should not expose private repository information.

## Success Criteria

The player gets a Signal for exploring the Unmark presentation while the feature remains professionally readable.
