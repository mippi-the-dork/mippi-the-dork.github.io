**Feature summary:** Advances cursor power and Mippi Bird extra-life progression through the Mushroom collectible.

## Internal Pickup Kind

Mushroom uses:

```text
kind:'1up'
```

in the standard pickup list.

Its SVG class is:

```text
pickup-mushroom
```

## Storage

Mushroom progress:

```text
mippi-mushroom-progress-v1
```

Banked lives:

```text
mippi-bird-mushroom-lives-v1
```

## Startup

Progress is clamped:

```text
0 through 19
```

Banked lives are nonnegative.

## Collection Order

`handleGamePickup()` for `1up`:

1. increments Mushroom telemetry,
2. calls `recordMushroomCollection()`,
3. creates visual explosion,
4. calls `advanceCursorPower()`.

This means the toast generated by cursor power can report the updated Mushroom life progress.

## Persistent Life Progress

`recordMushroomCollection()` increments:

```js
mushroomLifeProgress++;
```

At 20:

```js
mushroomLifeProgress-=20;
mushroomBankLives++;
```

It then records:

```text
economy.mushroomLivesEarned
meaningful: mushroom_extra_life_earned
```

and announces the banked life.

At 10/20, the Console prints a halfway progress message.

## Persistence

`persistMushroomLives()` writes both:

```text
MUSHROOM_PROGRESS_KEY
MUSHROOM_LIVES_KEY
```

and refreshes the Mippi Bird life HUD.

## Cursor Power

Runtime-only variable:

```js
let cursorPowerLevel=0;
```

`advanceCursorPower()` performs:

```js
cursorPowerLevel=
  (cursorPowerLevel+1)%3;
```

Body classes:

```text
cursor-grown
cursor-power-1
cursor-power-2
```

represent the current visual state.

## Legendary Combo

When:

```js
document.body.classList.contains(
  'theme-legendary'
)
```

and power level is above zero, the system records:

```text
combos.legendaryMushroom
```

and announces the combo.

Note that the current combo check is tied to Legendary visual class for the announcement/range note in this function. Legendary projectile gameplay elsewhere is progression-owned. If theme/gameplay separation is further tightened later, this specific Mushroom integration should be re-audited.

## Mippi Bird Use

`absorbFlappyHit()` checks Shop shield first.

If unavailable and:

```js
mushroomBankLives>0
```

it decrements one banked life, persists, and gives temporary invulnerability.
