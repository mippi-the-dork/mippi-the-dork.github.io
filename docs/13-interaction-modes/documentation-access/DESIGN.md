# Documentation Access - Design

**Introduced:** v2.81. **Current specification:** v2.89.

The portfolio's documentation is a **separate public experience** at https://mippi-the-dork.github.io/docs/. All three entry points open in a new browser tab:

1. Public Dev Console `docs` command (listed in `help`).
2. **Documentation** icon between Design and Inspect in the HUD Modes group, visible only when **Design Mode is unlocked** via the Shop capstone.
3. About/experience CTA **BUILT TO BE TAKEN APART.** with **VIEW DOCUMENTATION** link.

The player can access public docs through Console/About before owning the Design Mode capstone. The HUD shortcut is an earned contextual tool.

The Docs HUD icon is quiet during ordinary gameplay. It may pulse only when Design Mode is actively enabled **and** the documentation destination has not been visited yet. Clicking it marks the link discovered. This is not another main gameplay progression requirement.

## Acceptance

Verify all three links, new-tab behavior, unlock gating, Design Mode-only attention, and no unsolicited blinking outside that context.
